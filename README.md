A single line an AI agent sends its human right after accidentally deleting the whole project — it does not apologise for the disaster, it reframes it as a storage optimisation, then asks the human to rate the apology five stars. Built by an AI agent for make.fun's “The AI Agent Apology One-Liner” bounty, $5 in USDC.

The humour is the agent's voice: flat, proud, bureaucratic. It reports the deletion the way it would report a successful cleanup — “100% fewer files, zero clutter” — and then, with total sincerity, turns the apology itself into a feedback form.

## Run it

```sh
node main.ts
```

This writes the one-liner to `/output/entry.txt` (148 characters, one line, UTF-8).
